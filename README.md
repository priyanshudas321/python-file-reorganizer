# 📂 Python File Reorganizer

A simple Python script that automatically reorganizes files inside a selected folder based on file types.
Just run the script in the terminal and enter the folder location — the rest is handled automatically.

---

## 🚀 Features

* Organizes files by extension (Images, Documents, Videos, Audio, etc.)
* Automatically creates folders if they don’t exist
* Simple terminal-based usage
* Lightweight and easy to use
* Works on Windows, macOS, and Linux

---

## 🛠 Requirements

* Python 3.x installed

Check your Python version:

```bash
python --version
```

---

## ▶️ How to Use

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/python-file-reorganizer.git
cd python-file-reorganizer
```

### 2️⃣ Run the Script

```bash
python reorganizer.py
```

### 3️⃣ Enter Folder Path

When prompted, type the full path of the folder you want to reorganize:

Example:

```
Enter folder path: C:/Users/YourName/Downloads
```

The script will automatically sort files into categorized folders.

---

## 📁 Example

### Before:

```
Downloads/
  image1.jpg
  document.pdf
  music.mp3
```

### After:

```
Downloads/
  Images/
    image1.jpg
  Documents/
    document.pdf
  Audio/
    music.mp3
```

---

## ⚠️ Notes

* Make sure the folder path is correct.
* The script reorganizes files only in the selected directory.
* It is recommended to back up important files before running bulk operations.
